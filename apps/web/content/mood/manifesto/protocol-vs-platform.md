# Protocol vs Platform

Platforms organize users through ownership.

Protocols organize participants through shared rules.

```text
Platform: User → Company → Service

Protocol: Participant → Network → Shared Rules
```

Platforms optimize experience.

Protocols optimize coordination.

MOOD does not reject platforms. Applications can still exist.

MOOD creates a coordination layer that applications can build upon.

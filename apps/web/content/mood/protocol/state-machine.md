# MOOD State Machine

## Overview

MOOD is modeled as a network state transition system. A valid action transforms one network state into another.

> STATE + ACTION + RULES = NEW STATE

## Network State

- Identity
- Agents
- Nodes
- Projects
- Contributions
- Proofs
- Reputation
- Rights
- Governance
- Treasury

## State Transition

Participant creates contribution → Evidence submitted → Verification performed → Contribution accepted → Reputation updated → Rights or settlement generated

## Principle

MOOD does not only record transactions. It records meaningful state changes in a coordination network.

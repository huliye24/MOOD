# MOOD Protocol

## Public rules for open coordination.

- **Identity** — Who participates?
- **Contribution** — What value is created?
- **Proof** — How is it verified?
- **Reputation** — How does history accumulate?
- **Rights** — How does participation evolve?
- **Settlement** — How does value move?

```text
IDENTITY → CONTRIBUTION → PROOF
                         ↓
REPUTATION → RIGHTS → SETTLEMENT
```

The protocol is downstream of the Canon. These modules define concepts and boundaries; they do not claim that a production network or settlement system is active.

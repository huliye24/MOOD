# Reputation Engine

## Purpose

Reputation represents historical contribution. It is different from token ownership.

> Token = Transferable economic asset.  
> Reputation = Historical network trust.

## Properties

- Traceable
- Domain specific
- Evidence based
- Explainable

## Example Domains

- Development reputation
- Research reputation
- Verification reputation
- Node reliability
- Agent reliability

## Principle

Capital can participate. But capital alone should not define reputation.

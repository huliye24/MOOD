# Treasury Design

## Purpose

Treasury manages shared network resources. Treasury is not a promise of returns. It is a coordination resource.

## Possible Functions

- Protocol development
- Research
- Grants
- Infrastructure
- Security audits
- Ecosystem programs

## Transparency Requirements

- Public records
- Authorization rules
- Governance references
- Historical accountability

## Principle

A network treasury belongs to the network, not hidden operators. This document defines a design concept; it does not assert an active treasury.

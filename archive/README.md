# MOOD Historical Archive

This directory preserves imported packs, snapshots, PDFs, and staging-origin
material as historical evidence.

Nothing under `archive/` is current Canon, current protocol specification, a
deployment instruction, or proof that a mechanism is active. The archive may
contain superseded language, compatibility identifiers, duplicate files, and
old operational assumptions. Current authority begins with
[`MOOD_CANON.md`](../MOOD_CANON.md) and the active documents indexed under
[`docs/`](../docs/README.md).

Historical material should normally be preserved rather than cleaned into the
present. When an archived idea returns to active development, it must be
reviewed against the current Canon and reintroduced through an explicit active
document or proposal.

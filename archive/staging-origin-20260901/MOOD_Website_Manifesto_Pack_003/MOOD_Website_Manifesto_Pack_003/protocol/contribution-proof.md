# Contribution Proof System

## Purpose

Contribution Proof connects work with verifiable history.

A contribution should answer:

Who created value?

What was created?

When did it happen?

How can it be verified?


## Lifecycle

TASK

↓

EXECUTION

↓

EVIDENCE

↓

VERIFICATION

↓

CONTRIBUTION RECORD

↓

REPUTATION / RIGHTS / SETTLEMENT


## Contribution Types

Examples:

- Code
- Research
- Design
- Capital
- Data
- Compute
- Community
- Verification


## Principle

Evidence before reward.

Contribution must create a durable network record.

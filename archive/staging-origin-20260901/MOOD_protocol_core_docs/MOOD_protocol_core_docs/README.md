# MOOD Protocol Core Documents

MOOD is an open coordination protocol and digital world for human, AI agent, organization and resource coordination.

Core idea:

> Company owns resources → Protocol coordinates resources.

MOOD does not replace companies. It transforms companies, individuals, communities and capital providers into network participants.

Core layers:

- Identity
- Contribution
- Proof
- Reputation
- Agents
- Nodes
- Organizations
- Capital
- Governance
- Settlement

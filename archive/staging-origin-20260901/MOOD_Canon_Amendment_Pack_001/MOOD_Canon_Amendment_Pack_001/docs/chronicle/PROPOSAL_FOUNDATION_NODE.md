# Proposal: Foundation Node

Status:
Draft

Category:
Canon Amendment Proposal

## Purpose

Define the conceptual role of a Foundation Node inside the MOOD ecosystem.

## Motivation

As MOOD evolves from a project structure into a protocol civilization,
future stewardship roles require clear boundaries.

## Proposed Concept

Foundation Node is a stewardship actor.

It may:

- preserve documentation
- coordinate maintenance
- support protocol continuity

It does not:

- own the Canon
- control the Protocol
- represent all participants
- change rules without amendment

## Impact

Potential future updates:

- world documents
- constitution documents
- actor definitions

## Current State

Not ratified.
No implementation.
No organization established.

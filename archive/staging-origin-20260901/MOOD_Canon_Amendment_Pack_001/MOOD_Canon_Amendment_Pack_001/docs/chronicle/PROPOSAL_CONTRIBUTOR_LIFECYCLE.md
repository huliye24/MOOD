# Proposal: Contributor Lifecycle

Status:
Draft

Category:
Canon Amendment Proposal

## Purpose

Define a conceptual path from participation to recognized contribution.

## Proposed Lifecycle

Participant

↓

Contribution

↓

Proof

↓

Reputation

↓

Rights

## Principles

Contribution before reward.

Proof before claim.

Recognition should emerge from verifiable contribution.

## Current State

Concept only.
No automated reputation system exists.

# Proposal: Community Node

**Status:** Draft

**Category:** Canon Amendment Proposal — Phase Zero Batch A

**Authority:** Awaiting Canon Review. This document is a proposal only. It does not modify [`MOOD_CANON.md`](../../MOOD_CANON.md).

## Purpose

Define Community as a protocol participant category.

## Proposed Concept

Community Node represents groups of participants contributing to the MOOD network.

Possible participants:

- creators
- developers
- researchers
- supporters

## Principles

Community participation should be based on:

Contribution
Participation
Reputation

Not:

Permission
Status
Ownership

# Proposal: Contributor Lifecycle

**Status:** Draft

**Category:** Canon Amendment Proposal — Phase Zero Batch A

**Authority:** Awaiting Canon Review. This document is a proposal only. It does not modify [`MOOD_CANON.md`](../../MOOD_CANON.md).

## Purpose

Define a conceptual path from participation to recognized contribution.

## Proposed Lifecycle

Participant

↓

Contribution

↓

Proof

↓

Reputation

↓

Rights

## Principles

Contribution before reward.

Proof before claim.

Recognition should emerge from verifiable contribution.

# docs/chronicle

Chronicle holds living record of MOOD's ongoing Canon Amendment Proposals and
other long-form project proposals that have not yet been ratified into
[`MOOD_CANON.md`](../MOOD_CANON.md).

## Authority

Nothing in `docs/chronicle/` modifies the Canon. Files here are proposals,
drafts, or active deliberation only. The Canon is amended first; the system
follows (per `AGENTS.md`).

## Naming Convention

Proposal files use `PROPOSAL_<SCOPE>.md`. The scope indicates the subsystem
the proposal concerns (for example `FOUNDATION_NODE`,
`CONTRIBUTOR_LIFECYCLE`, `COMMUNITY_NODE`).

## Status Lifecycle

Proposals in this directory may transition through:

1. **Draft** — under authoring or active discussion
2. **Under Review** — submitted for Canon review
3. **Ratified** — accepted into `MOOD_CANON.md` (file archived or retired)
5. **Withdrawn / Rejected** — no longer active

Until a proposal is **Ratified**, it carries no canonical authority.

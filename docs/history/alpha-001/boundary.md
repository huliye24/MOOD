# Alpha 001 Boundary

## Implemented

- Proof
- Object
- Verification
- Storage
- API

## NOT IMPLEMENTED

- issuer signature, object registry, genesis object — Alpha 002
- synchronization transport — Alpha 003
- network state: reputation, governance, resource allocation — Alpha 004

## Future

- Alpha 002 — Identity Signature
- Alpha 003 — Synchronization
- Alpha 004 — Network State

No future feature should silently modify Alpha 001 assumptions.

Changes to the frozen surface — the v0.1 envelope, the ID derivation,
the hash algorithm — arrive as new alpha versions, never as edits to
Alpha 001.

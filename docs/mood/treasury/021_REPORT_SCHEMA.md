# 021 — Treasury Report Schema

**Date:** 2026-08-30

## Purpose

Define the canonical schema for monthly / snapshot treasury reports.

Reports are GENERATED, not invented. If no real data exists for a period, the report says "No data this period" rather than fabricate.

---

## Report Types

1. **Treasury Snapshot** — Point-in-time view.
2. **Monthly Report** — Aggregate over a calendar month.
3. **Execution Ledger** — Chronological list of executions.
4. **Allocation Report** — Per-category activity.
5. **Risk Notes** — Documented risks, custody, signer status.

---

## Canonical Schema (v1)

```ts
type TreasuryReportSchema = "moodify-treasury-report-v1";

interface TreasurySnapshotReport {
  schema: TreasuryReportSchema;
  generatedAt: string;
  periodStart: string;       // ISO
  periodEnd: string;         // ISO
  treasuryStatus: "inactive" | "observed" | "policy-ready" | "active" | "paused";
  accounts: TreasuryAccountReport[];
  assets: TreasuryAssetReport[];
  revenue: TreasuryRevenueReport[];
  allocations: TreasuryAllocationReport[];
  executions: TreasuryExecutionReport[];
  reconciliation: TreasuryReconciliationReport;
  risks: string[];
  governanceRefs: string[];
  notes?: string;
}
```

## Account Report Entry

```ts
interface TreasuryAccountReport {
  id: string;
  label: string;
  type: string;
  address?: string;       // only if public
  chain?: string;
  status: string;
  public: boolean;
  controlModel?: string;
  lastSync?: string;
}
```

## Asset Report Entry

```ts
interface TreasuryAssetReport {
  accountId: string;
  assetId: string;
  assetType: string;
  quantity?: string;
  valuationUsd?: string | null;     // null = unavailable
  valuationSource?: string;
  observedAt: string;
  verificationState: "verified" | "unverified" | "unavailable";
}
```

## Revenue Report Entry

```ts
interface TreasuryRevenueReport {
```

## Reconciliation Report

```ts
interface TreasuryReconciliationReport {
  verified: number;
  mismatch: number;
  unavailable: number;
  stale: number;
  mismatches: Array<{
    accountId: string;
    config: string;
    rpc: string;
    cached: string;
    note?: string;

}
```

## Storage Path

Reports stored under:

```text
docs/mood/treasury/reports/YYYY-MM.md   (Markdown)
docs/mood/treasury/reports/YYYY-MM.json (JSON, machine-readable)
```

If no data for a month, the file exists but contains:

```text
No treasury data this period.

Treasury status: Not Activated
Accounts: 0
Executions: 0
Allocations: 0

This is consistent with the actual inactive state. No fabricated data.
```

---

## Generation Rule

021 does NOT generate reports automatically. Reports are generated by:

- Maintainer (manual)
- Future report tooling (separate package)

Until then, the canonical "report" is the read-only `/treasury` page + `/api/protocol/treasury` JSON.

# MOOD Economy

**Status:** Conceptual Boundary  
**Authority:** Subordinate to `MOOD_CANON.md`

The economy serves the MOOD world. It does not define the world.

This directory will hold explicit authority documents for value, scarcity,
incentives, ownership, rewards, penalties, treasury functions, settlement, and
long-term sustainability. Until those documents are accepted, existing token
contracts, markets, application configuration, and experimental code are facts
or implementation material—not proof of an active MOOD protocol economy.

## Current boundary

- No token reward mechanism is canonically activated here.
- No staking or token-weighted governance is canonically activated here.
- No treasury or distribution mechanism is canonically activated here.
- The final role of the existing Moodify-named token remains unresolved.

See [Decision 001](../chronicle/decisions/DECISION_001_MOODISM_IDENTITY.md).

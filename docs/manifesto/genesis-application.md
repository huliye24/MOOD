# MOOD Manifesto

## Genesis Application

**Status:** Canonical Draft  
**Category:** Manifesto / Application Boundary  
**Protocol:** MOOD Protocol

A genesis application is an early independent implementation that tests protocol ideas against real work. It is evidence and a participant, not the protocol itself.

Moodify may serve as an independent genesis application for sound intelligence:

- audio intelligence;
- sound analysis;
- creator tools;
- AI listening;
- music research.

These responsibilities belong to Moodify's repository and product boundary. They must not be implemented as root MOOD identity, governance, contribution, reputation, or settlement semantics.

> Sound may be an entrance into MOOD. It is not the boundary of MOOD.

Calling an application “genesis” grants no permanent authority, privileged governance position, exclusive integration right, or ownership of the network.

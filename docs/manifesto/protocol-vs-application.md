# MOOD Manifesto

## Protocol vs. Application

**Status:** Canonical Draft  
**Category:** Manifesto / Product Boundary  
**Protocol:** MOOD Protocol

A protocol defines shared rules. An application offers a bounded experience.

MOOD is responsible for general coordination primitives:

- identity;
- contribution;
- proof;
- reputation;
- rights;
- governance;
- settlement.

An application is responsible for its own domain semantics, interface, users, operations, and product value.

No application may become the hidden constitutional center of MOOD. Applications may disappear, compete, fork, or be replaced without changing what MOOD is.

The protocol does not inherit an application's market, brand, data model, or specialist vocabulary by default.

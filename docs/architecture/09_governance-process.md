# Governance Process

Governance lifecycle:

1. Proposal creation
2. Community discussion
3. Review and evaluation
4. Decision process
5. Execution
6. Outcome review

The goal is continuous improvement.

---

> Each step is described as an aspiration. Submission templates,
> review checklists, and execution authority are not specified in
> this document. Per `MOOD_CANON.md` §9, AI agents and autonomous
> agents do not hold constitutional authority in MOOD governance.

# MOOD State Machine

## Participant Lifecycle

```
Observer

Can view the network.

↓

Participant

Joins the ecosystem.

↓

Contributor

Creates measurable value.

↓

Trusted Contributor

Builds reputation.

↓

Network Member

Receives broader rights.
```

> Each transition is described here as an aspirational direction. The
> conditions, evidence requirements, and on-chain hooks for these
> transitions are not finalized in this document. Future implementations
> may connect states with on-chain and off-chain proofs, but no such
> implementation is asserted here.

This state machine maps onto `MOOD_CANON.md` §6.4 (Protocol) and should
not be implemented as production logic until a specification document
with verifiable evidence requirements is authored.

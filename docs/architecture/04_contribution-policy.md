# MOOD Contribution Policy

Contribution is the foundation of MOOD.

Examples:

## Technical Contribution

- code
- architecture
- security
- infrastructure

## Creative Contribution

- design
- content
- culture

## Resource Contribution

- compute
- data
- capital

## Ecosystem Contribution

- community
- partnerships
- education

All contributions should be documented and verifiable.

---

> This policy enumerates types of contribution. It does not define how
> contributions are recorded, weighted, or rewarded. Those questions
> belong to the Contribution Proof system (`05_contribution-proof.md`)
> and the Reputation Engine (`06_reputation-engine.md`), both of which
> remain at the conceptual stage.

# Contribution Proof

Contribution Proof answers:

"What value was created?"

Examples:

## Code

- commits
- pull requests
- security improvements

## Research

- papers
- experiments
- discoveries

## Compute

- AI inference
- infrastructure services

## Ecosystem

- communities
- partnerships
- education

Proof creates trust.

---

> The mechanism by which proof is recorded, verified, and weighted is
> not specified here. This document describes categories of proof; the
> proof pipeline itself remains planned.

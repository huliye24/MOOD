# MOOD State Machine

**Status:** Phase Zero foundational draft

**Authority:** Downstream of [`MOOD_CANON.md`](../../MOOD_CANON.md)

## Overview

MOOD is modeled as a network state transition system.

A valid action transforms one network state into another.

Concept:

STATE + ACTION + RULES = NEW STATE


## Network State

The logical state includes:

- Identity
- Agents
- Nodes
- Projects
- Contributions
- Proofs
- Reputation
- Rights
- Governance
- Treasury


## State Transition

Example:


Participant creates contribution

↓

Evidence submitted

↓

Verification performed

↓

Contribution accepted

↓

Reputation updated

↓

Rights or settlement generated


## Principle

MOOD does not only record transactions.

It records meaningful state changes in a coordination network.

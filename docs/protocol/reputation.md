# Reputation Protocol

**Status:** Phase Zero foundational draft

**Authority:** Downstream of [`MOOD_CANON.md`](../../MOOD_CANON.md)

MOOD separates economic value from the memory of contribution:

```text
Token
=
economic value

Reputation
=
historical contribution
```

Reputation should be:

- Traceable
- Domain-specific
- Evidence-based
- Non-transferable

Reputation is not a universal score, a transferable asset, or automatic governance authority. Its calculation, scope, expiry, dispute process, and relationship to rights remain to be specified.

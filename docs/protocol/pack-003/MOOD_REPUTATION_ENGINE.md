# Reputation Engine

Reputation converts contribution history into network trust.

A future reputation model may include:

- contribution volume
- quality assessment
- long-term consistency
- network impact
- collaboration quality

Reputation should not be purchased.

It should be built.

---

> The reputation formula, decay rules, anti-sybil mechanisms,
> anchoring layer, and migration between off-chain and on-chain
> representation are not finalized in this document. Implementation
> requires a specification, a test plan, and verifiable evidence
> before any live deployment.
>
> Per `MOOD_CANON.md` §12, reputation that drives economic
> distribution is downstream. No token distribution curve is
> asserted here.

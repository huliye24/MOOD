# Governance Process

Governance lifecycle:

1. Proposal creation
2. Community discussion
3. Review and evaluation
4. Decision process
5. Execution
6. Outcome review

The goal is continuous improvement.

---

> Each step is described as an aspiration. Submission templates,
> review checklists, quorum requirements, veto mechanisms, and
> execution authority are not specified in this document.
>
> Per `MOOD_CANON.md` §9, AI agents and autonomous agents do not
> hold constitutional authority in MOOD governance. Any
> governance-related implementation must preserve human approval
> gates for irreversible decisions (Canon §Safety).

## Canon Alignment

- **§4 Canon is source of authority:** Governance rules are
  downstream of canonical documents.
- **§9 Canon-First Agent Law:** Agents do not hold constitutional
  authority.
- **§14 Canonical change:** Governance process changes are
  constitutional amendments, not local edits.
- **§Safety:** Human approval gates required for deployment,
  treasury, token activation, and irreversible public actions.

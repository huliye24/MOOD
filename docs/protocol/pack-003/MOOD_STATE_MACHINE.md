# MOOD State Machine

## Participant Lifecycle

```
Observer

Can view the network.

↓

Participant

Joins the ecosystem.

↓

Contributor

Creates measurable value.

↓

Trusted Contributor

Builds reputation.

↓

Network Member

Receives broader rights.
```

Future implementations may connect states with on-chain and off-chain proofs.

---

> Each transition is described as an aspirational direction. The
> specific evidence required to advance between states (e.g. minimum
> contribution record, peer-review threshold, anti-sybil checks) is
> not specified in this document. Transition logic must not be
> implemented as production behavior until an authoritative
> specification with verifiable evidence requirements is authored.
>
> This state machine is conceptually aligned with
> `docs/architecture/03_state-machine.md` (Network Architecture Pack
> 001). Where the two diverge, the disagreement returns to the Canon.

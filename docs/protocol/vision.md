# MOOD Vision

**Status:** Phase Zero foundational draft

**Authority:** Downstream of [`MOOD_CANON.md`](../../MOOD_CANON.md)

Bitcoin created decentralized money.

Ethereum created programmable state.

MOOD explores open coordination state for humans, AI agents, organizations, capital, and network resources.

The future network is not limited to:

```text
Employee → Company
```

It can also support:

```text
Participant → Project → Contribution → Reputation → Rights
```

MOOD does not replace companies. It provides a shared coordination layer through which people, organizations, agents, and resources may participate in projects under explicit rules.

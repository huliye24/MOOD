# Contribution Protocol

**Status:** Phase Zero foundational draft

**Authority:** Downstream of [`MOOD_CANON.md`](../../MOOD_CANON.md)

MOOD records contribution instead of recognizing only employment.

## Contribution Types

- Code
- Research
- Design
- Capital
- Compute
- Data
- Community
- Verification

## Lifecycle

```text
TASK
  ↓
EXECUTION
  ↓
EVIDENCE
  ↓
VERIFICATION
  ↓
CONTRIBUTION RECORD
  ↓
REPUTATION / RIGHTS / SETTLEMENT
```

A contribution record does not automatically create reputation, rights, or settlement. Each downstream result requires its own policy, evidence, and verification rules.

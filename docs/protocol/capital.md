# Capital Coordination Protocol

**Status:** Phase Zero foundational draft

**Authority:** Downstream of [`MOOD_CANON.md`](../../MOOD_CANON.md)

MOOD is a coordination protocol, not an investment platform. This document defines capital as one participant and resource type within a broader contribution network; it does not describe an active investment product or authorize fundraising, token distribution, or treasury movement.

## From Investment to Participation

Traditional:

```text
Investor → Company → Employee → Product
```

MOOD explores:

```text
Capital Node → Project → Contribution Network → Settlement
```

## Project Passport

Every project may contain:

- Mission
- Roadmap
- Contributors
- Treasury
- Evidence
- Rights
- Revenue records

The Project Protocol defines the project as the coordination context. Capital does not define the project's mission or automatically receive governance authority.

## Transparent Treasury

All important capital movements should be:

- Recorded
- Auditable
- Verifiable
- Governed

No treasury or settlement mechanism is presumed active without verifiable evidence and the required human approval.

## Principle

Capital is one type of contribution, not the only source of authority.

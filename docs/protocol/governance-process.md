# Governance Process

**Status:** Phase Zero foundational draft

**Authority:** Downstream of [`MOOD_CANON.md`](../../MOOD_CANON.md)

## MOOD Improvement Proposal (MIP)

Protocol changes should follow a visible process.


Lifecycle:


DRAFT

↓

DISCUSSION

↓

REVIEW

↓

VOTE

↓

ACCEPTED / REJECTED

↓

EXECUTED


## Governance Principles

- Transparent discussion
- Version control
- Public reasoning
- Accountability


## Purpose

Governance does not remove leadership.

It makes decision processes visible and accountable.

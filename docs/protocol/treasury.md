# Treasury Design

**Status:** Phase Zero foundational draft

**Authority:** Downstream of [`MOOD_CANON.md`](../../MOOD_CANON.md)

## Purpose

Treasury manages shared network resources.

Treasury is not a promise of returns.

It is a coordination resource.


## Treasury Functions

Possible uses:

- Protocol development
- Research
- Grants
- Infrastructure
- Security audits
- Ecosystem programs


## Transparency Requirements

Treasury actions should include:

- Public records
- Authorization rules
- Governance references
- Historical accountability


## Principle

A network treasury belongs to the network, not hidden operators.

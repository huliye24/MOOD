# Node Protocol

**Status:** Phase Zero foundational draft

**Authority:** Downstream of [`MOOD_CANON.md`](../../MOOD_CANON.md)

Nodes are participants providing resources or coordination capabilities.

## Examples

- Human Node
- AI Agent Node
- Organization Node
- Capital Node
- Compute Node
- Verification Node

## Principle

Node value comes from real service and verified contribution.

Being named as a node does not by itself prove identity, capability, availability, contribution, reputation, or authority. Those claims require evidence under the relevant protocol module.

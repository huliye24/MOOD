# MOOD Lexicon

**Status:** Foundational Draft  
**Authority:** Subordinate to `MOOD_CANON.md`

The Lexicon keeps identity-critical terms legible across Chinese, English,
documents, schemas, and software. It defines conceptual distinctions; it does
not activate protocol or economic mechanisms.

- [中文词典](LEXICON_ZH.md)
- [English Lexicon](LEXICON_EN.md)

When translations diverge materially, the divergence must be documented and
resolved through a canonical change. Software identifiers do not silently
settle conceptual disagreements.
